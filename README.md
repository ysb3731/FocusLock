# 숨 고르기 (FocusLock) · Android 2단계

집중 시간 동안 내가 고른 앱(유튜브·인스타그램 등)이 열리면 홈으로 돌려보내고 차단 화면을 띄우는 앱입니다.
1단계 웹앱과 같은 흐름·색을 씁니다.

## 기능
- 집중 시간 15·25·50·90분, 엄격/유연 모드
- 차단 앱 직접 선택 (기본값: 유튜브, 인스타그램, 틱톡, 페이스북, 네이버)
- 차단 화면: 남은 시간 안내 + "나중에 할 일" 메모
- 유연 모드: 10초 기다리면 그 앱만 5분 허용
- 엄격 모드: 3초 길게 눌러야 포기
- 집중 완료 알림, 오늘 완료 수·연속 달성일·7일 집중 시간·참은 유혹 기록
- 외부 라이브러리 없음 (Android 기본 API만 사용), 최소 Android 8.0

## 빌드 방법 A: GitHub 자동 빌드 (PC에 아무것도 설치 안 함)
`.github/workflows/build.yml` 이 들어 있어서, GitHub에 올리면 자동으로 APK가 만들어지고
저장소의 **Releases** 에 `FocusLock.apk` 로 올라갑니다. 코드를 고쳐 다시 올릴 때마다 새 APK가 생깁니다.

## 빌드 방법 B: Android Studio (약 20~30분, 처음 1회)
1. PC에 **Android Studio** 설치 (developer.android.com/studio)
2. 압축을 풀고 Android Studio에서 **Open → FocusLock 폴더** 선택
3. 하단 Gradle 동기화가 끝날 때까지 대기 (SDK 34가 없으면 설치 안내가 뜸 → 설치)
4. 휴대폰: 설정 › 휴대전화 정보 › 소프트웨어 정보 › **빌드번호 7번 탭** → 개발자 옵션 › **USB 디버깅 켜기**
5. USB로 연결 후 상단 ▶(Run) 클릭 → 폰에 설치됨
   - APK 파일만 필요하면: Build › Build App Bundle(s)/APK(s) › Build APK(s)

## 처음 실행 후 설정
1. 앱 상단 **"접근성 설정 열기"** → 설치된 앱 › **숨 고르기 앱 차단** 켜기
   (삼성: 설정 › 접근성 › 설치된 앱)
2. 알림 권한 허용 (완료 알림용)
3. **차단할 앱 편집**에서 막을 앱 선택 → 저장
4. 삼성폰은 설정 › 애플리케이션 › 숨 고르기 › 배터리 › **제한 없음** 권장 (백그라운드 종료 방지)

## 알아둘 점 (리스크)
| 항목 | 내용 | 대응 |
|---|---|---|
| 접근성 권한 | 화면 맨 앞 앱의 이름(패키지명)만 확인. 화면 글자·입력값은 읽지 않도록 설정함 (`canRetrieveWindowContent=false`) | 개인 사용엔 문제없음 |
| 구글 플레이 출시 | 장애 보조 목적이 아닌 접근성 API 사용은 **사전 고지 화면 + 플레이 콘솔 신고서**가 필요하고 심사 거절 사례가 많음 | 우선 직접 설치(사이드로드)로 사용. 출시하려면 사용 통계(UsageStats) 방식 전환 검토 |
| 우회 가능성 | 접근성 설정을 꺼 버리면 차단이 풀림 | 자기 통제용 앱의 한계. 3단계에서 "설정 화면 열기도 차단" 옵션 추가 가능 |
| 알림 시각 | 정확한 알람 권한 없이 쓰므로 수십 초 늦을 수 있음 | 타이머 화면은 정확함 |
| 아이폰 | 이 코드는 Android 전용. iOS는 Screen Time API(Swift)와 애플 별도 승인 필요 | 별도 프로젝트 |

## 파일 구조
```

  MainActivity.kt              타이머·설정·메모·기록 화면
  BlockAccessibilityService.kt 차단 앱 감지 → 차단 화면 띄움
  BlockActivity.kt             차단 화면 (메모, 유연 모드 10초 대기)
  AppPickerActivity.kt         차단할 앱 선택
  FinishReceiver.kt            집중 완료 알림
  FocusStore.kt                저장소 (세션·기록·메모)
  Ui.kt                        색·버튼 등 화면 도우미
```
